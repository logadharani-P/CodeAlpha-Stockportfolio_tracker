

# Stock_portfolio_tracker

## Description

This is a simple stockportfolio tracker built using python.It is very useful calculating the total portfolio price.

## Technologies

- python
- vs code
- matplotlib

## How to run

- open the file
- open terminal 
type
  python stockportfoliotracker.py

## steps

- First enter the number of elements 
- Enter the name of one by one
- Enter the shares of one by one
- Enter the price of each stocks
- finally it calculate the total
